# ytmGO 0.0.61

The project now uses the 0.0.x version series, starting at 0.0.61. This release retains the current application features and fixes, including continuous playlist and album track numbering across pages, configurable video quality, playback-state restoration, and native update menus.

The original 0.5.x and 0.6.x GitHub Releases have been retired. Source history and historical verification records are retained. Subsequent releases will increment from 0.0.61.

macOS 13 or newer, Apple Silicon and Intel. macOS packages are Developer ID signed, notarized and stapled; all four release targets use Ed25519-signed update archives. Windows installers are not Authenticode signed.
