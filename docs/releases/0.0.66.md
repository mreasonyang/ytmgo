# ytmGO 0.0.66

- Choose Data saver, Standard or Highest available audio quality in Settings. The preference is remembered and applies when a song is next loaded.
- Download songs, albums and playlists for offline listening. Downloads are encrypted on disk, separated by account, and managed from the library sidebar with progress, pause, resume and removal controls. Completed audio remains playable after restarting without a network connection.
- Select several songs with the mouse, drag across rows or use Select All, then act on the selection together.
- Updated library navigation, top-bar alignment, download artwork, in-app confirmation and About dialogs, and the native update window. Now Playing and Immersive Mode move together with the page; library labels show tips when truncated.
- Playback and video updates now follow native state and frame events, with a fallback while playback is active. Track endings advance the queue, and the next prepared decoder can be reused.
- Recover pagination when a continuation response cannot be used, and start lyrics at the top with the sung line a third of the way down.

macOS 13 or newer, Apple Silicon and Intel. macOS release packages are Developer ID signed, notarized and stapled. All four release targets use Ed25519-signed update archives; Windows installers are not Authenticode signed.
