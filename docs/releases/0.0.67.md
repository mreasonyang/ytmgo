# ytmGO 0.0.67

- Collection covers now travel between the selected card or library row and the collection page, with the page colour blending along the way. Downloads uses the same transition and has a collection header.
- Immersive Mode grows from the current page while its cover and Now Playing content move into place. Returning restores the previous page and panel.
- Settings, keyboard shortcuts, About and confirmation dialogs now share consistent opening and closing motion. Reduced-motion preferences show the final state immediately.

macOS 13 or newer, Apple Silicon and Intel. macOS release packages are Developer ID signed, notarized and stapled. All four release targets use Ed25519-signed update archives; Windows installers are not Authenticode signed.
