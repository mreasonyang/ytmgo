# ytmGO 0.0.68

- Covers already cached in memory stay visible when you scroll back to them, including when the view needs a different image size.
- Briefly scrolling past a cover can reuse its in-progress download. The current track's cover takes priority when artwork requests compete for capacity.
- Newly visible covers load after resizing the window or rearranging the page while playback is paused.
- Downloaded covers follow the active library. Removing a download or switching libraries clears outdated artwork and its colour.

macOS 13 or newer, Apple Silicon and Intel. macOS packages are Developer ID signed, notarized and stapled. Signed update archives accompany the platform packages.
