# ytmGO 0.6.10

Playlist and album row numbers now continue across track pages instead of restarting at 1 for each continuation. For example, a first page ending at 98 is followed by 99, 100 and the remaining tracks.

Empty continuation pages do not advance or reset the numbering. Suggestions and other named sections remain independent, and a separate track list starts its own sequence. Row activation retains the same playback target.

Native rendering regressions cover playlist and album pages in wide and compact layouts, multiple continuations, empty shelves, repeated frames, independent sections and four-digit row labels.

macOS 13 or newer, Apple Silicon and Intel. macOS packages are Developer ID signed, notarized and stapled; all four release targets use Ed25519-signed update archives. Windows installers are not Authenticode signed.
