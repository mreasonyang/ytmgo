ytmGO 0.6.3 brings the latest native lyrics, library and playback improvements to macOS arm64, Windows x64 and Linux x64 desktop packages.

- Drag synchronized lyrics vertically and release to seek to the selected line, keeping the current play/pause state. Expand the lyrics area and keep that layout across restarts.
- Keep lyric highlighting on the decoder's audio clock. Fix AAC/Opus seeks and restored bookmarks when container timestamps or fragment preroll differ from the recording timeline.
- Restore the full saved library immediately, preserve paginated snapshots, and keep restored playback paused after reconnecting.
- Improve scrolling over horizontal shelves, lyric following in short windows, and seek/volume previews.
- Unify the display name and app bundle as **ytmGO**. Existing bundle identifiers, encrypted account sessions and data directories are retained.
- Add Homebrew installation through the **mreasonyang/taps** tap. Original project code is now licensed under **Apache-2.0**; bundled third-party licenses and corresponding sources remain included.

**macOS download:** requires **macOS 27 or later on Apple Silicon**. The Mac app and DMG are Developer ID signed, notarized and stapled.

Install the Linux DEB with `sudo apt install ./ytmgo_0.6.3_amd64.deb`. Extract portable packages completely and retain their resource directories beside the executable. All three platforms use Ed25519-signed update archives. Windows/Linux checksums and build receipts are published separately from the Mac files.

Install on macOS with Homebrew:

```sh
brew install --cask mreasonyang/taps/ytmgo
```

Update a Homebrew installation:

```sh
brew update
brew upgrade --cask --greedy mreasonyang/taps/ytmgo
```

Existing installations can also use **ytmGO → Check for Updates…**. Quit ytmGO before switching installation methods. For a manually installed copy, keep a backup and move the existing app out of `/Applications` before running the Homebrew install command.

Windows/Linux packages passed native builds, offline runtime tests, actual NSIS/DEB installation, installed-resource/version verification and startup in an empty account profile. Real-account Windows/Linux E2E, physical global shortcuts, hardware audio, sleep/wake and long-duration reliability remain outside that smoke-test scope.
