# ytmGO 0.6.5

Video now defaults to **720p**, with **144p, 240p, 360p, 480p, 720p and 1080p** available beside the Cover / Video switch and in Settings. Your last choice is saved immediately and retained across track changes, window closure and app restarts. Changing quality reloads video at the current audio position while audio continues. If the requested source resolution is missing, the player prefers a lower available source; it never enlarges a smaller source during decoding. Video presentation remains at 24fps.

- Reuse catalog, queue, lyrics and fresh public proof-script results, and preserve current playback and next-track preparation when account status has not changed.
- Recover interrupted media ranges with bounded retries of only undelivered bytes, and follow validated YouTube media CDN redirects without forwarding account headers.
- Let native streaming recovery finish without a competing FFmpeg read timeout. Preserve specific playback failure categories and bounded HTTP status codes when a stream fails.
- Separate video source resolution from the decoder's first-frame deadline, so cold initialization does not prematurely consume the frame startup budget.
- Retry timed-lyrics lookup after temporary failures instead of caching plain fallback text as a complete result for ten minutes.
- Read compressed proof initialization pages with bounded compressed and expanded sizes, and record only fixed catalog error categories, allowed stages and numeric timing metadata.
- Report the actual packaged version in playback and account diagnostics and acceptance receipts.

macOS downloads support **macOS 13 or newer**, on **Apple Silicon and Intel**. Both macOS apps and DMGs are Developer ID signed, notarized and stapled, with architecture-specific Ed25519-signed update archives. Windows x64 and Linux x64 packages are also published, with native installation/startup checks and Ed25519-signed update archives. The Windows installer is not Authenticode signed.

Local verification covers real 1280×720 YouTube MV playback, bundled FFmpeg output at 720p/1080p/360p, saved preferences, four-language quality controls, and audio/video recovery regressions. Native package smoke tests run separately for each release target. Physical global-shortcut activation, sleep/wake, macOS 13/14 hardware, signed-in Intel/Windows/Linux playback and long-running acceptance remain outside this release's verification.
