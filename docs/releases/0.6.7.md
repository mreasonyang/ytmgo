# ytmGO 0.6.7

Large playlists now load their remaining tracks before requesting recommended songs. The playlist track cursor takes priority over the surrounding section cursor; the recommendation cursor is retained and resumes after the track list ends.

Each stream keeps its original request mode, payload and visitor context. Empty pages with more tracks remain pageable, failed requests can be retried, and signing out or switching accounts invalidates both streams.

Offline regressions cover 127- and 2,723-track playlists, both continuation request formats, empty pages, retries, visitor isolation and expired handles.

macOS 13 or newer, Apple Silicon and Intel. macOS packages are Developer ID signed, notarized and stapled; in-app updates verify a separate Ed25519 signature. Windows and Linux packages are built from the same released source.
